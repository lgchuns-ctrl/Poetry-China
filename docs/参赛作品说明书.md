# 参赛作品说明书

## 一、作品名称

**诗行中国——唐诗宋词中的山河地图**

## 二、作品简介

本项目是一个数字人文研究与应用作品，通过对 21,008 首唐诗宋词的系统性数据挖掘，提取其中的地理地名信息，映射到现代中国地图上，以交互式可视化的方式展现唐宋诗词中的山河版图。

作品涵盖唐诗 15,008 首、宋词 6,000 首，覆盖 1,141 位诗人，识别 190 个文学地点，提取 5,341 次地名提及。通过多维度的数据分析和可视化呈现，让使用者能够"循诗而行"，在千年文字中重新看见中国山河。

## 三、作品类型

数字人文 / 数据可视化 / 交互式网页应用

## 四、技术架构

| 层级 | 技术 | 说明 |
|------|------|------|
| 数据采集 | Node.js | 从 GitHub 开源项目下载诗词数据 |
| 数据处理 | Python 3.12 | 繁简转换、NER、分析、导出 |
| 繁简转换 | opencc-js | 繁体→简体中文 |
| 前端框架 | Vue 3 + TypeScript | SPA 单页应用 |
| 构建工具 | Vite 5 | 开发服务器+构建 |
| 可视化 | ECharts 5 | 地图散点图、柱状图 |
| 地图数据 | DataV.GeoAtlas | 中国省级 GeoJSON |

## 五、核心功能

### 1. 诗词地图
- ECharts 中国地图散点可视化
- 190 个文学地点按类型分形状、按频次分大小
- 朝代/诗人/主题/意象 四维筛选
- 点击地点查看详情（关联诗人、作品、意象、主题、置信度）

### 2. 唐宋对比
- 地名、类型、意象、主题 四个维度
- 左右并排柱状图直观对比
- 数据驱动，附局限性声明

### 3. 诗人行迹
- 个体诗人地理分布地图
- 统计卡片展示作品数、地名覆盖
- 代表作品展示

### 4. 全文检索
- 跨正文/标题/作者/地名搜索
- 关键词高亮
- 快捷搜索按钮

### 5. 数据方法
- 完整的数据处理流程展示
- NER 质量验证结果
- 古今地名映射说明
- 数据驱动结论

## 七、创新点

1. **三重地名区分**：区分诗中提及地、诗人写作地、诗人生平地
2. **置信度分级**：古今地名映射分 6 级，标注可靠性
3. **多维交叉分析**：地名 × 朝代 × 诗人 × 主题 × 意象
4. **数据驱动结论**：8 条研究结论由程序自动生成
5. **NER 质量验证**：150 条随机抽样，100% 精确率
6. **排除词机制**：30+ 排除词减少误识别
7. **水墨视觉风格**：宣纸白+墨黑+朱砂的古典美学

## 八、数据来源

1. **诗词文本**：chinese-poetry（GitHub，MIT 许可证）
   - https://github.com/chinese-poetry/chinese-poetry
2. **地图数据**：DataV.GeoAtlas（阿里云）
   - https://geo.datav.aliyun.com
3. **繁简转换**：opencc-js（MIT 许可证）

所有数据均来自公开开源项目，无版权风险。
