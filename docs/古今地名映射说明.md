# 古今地名映射说明

## 一、映射方法

本项目将唐宋诗词中的历史地名映射到现代地理位置，采用**词典映射法**，即在地名词典中为每个历史地名预先标注其现代对应位置和经纬度坐标。

### 映射流程

```
历史地名 → 词典查找 → 现代名称 → 省份/城市 → 经纬度坐标 → 映射级别评估
```

## 二、映射级别

根据映射的精确程度，分为 6 个级别：

| 级别 | 说明 | 示例 | 可靠性 |
|------|------|------|--------|
| `exact` | 历史地名与现代地名完全对应 | 华山→华山（陕西华阴） | 最高 |
| `city` | 映射到现代地级市 | 长安→西安市 | 高 |
| `county` | 映射到现代县/区 | 奉节→奉节县 | 高 |
| `province` | 映射到省级区域 | 河西→甘肃省 | 中 |
| `approximate` | 大致位置 | 塞北→北方边疆地区 | 低 |
| `region` | 泛指区域 | 江南→长江以南地区 | 最低 |

### 各级别数量分布

| 级别 | 数量 | 占比 |
|------|------|------|
| exact | ~40 | 21% |
| city | ~70 | 37% |
| county | ~20 | 10% |
| province | ~15 | 8% |
| approximate | ~20 | 10% |
| region | ~25 | 13% |

## 四、别名处理

部分历史地名有多个别称，在词典中统一收录为别名，匹配时自动归并到规范名称：

| 规范名称 | 别名 |
|----------|------|
| 长安 | 镐京、大兴、常安 |
| 南京 | 建康、金陵、江宁、石头城 |
| 杭州 | 临安、钱塘、武林 |
| 开封 | 汴京、汴梁、东京 |
| 西安 | 长安、西京 |
| 成都 | 锦官城、蓉城 |

## 五、坐标来源

地名坐标主要来源于：
1. **百度百科/维基百科**：城市和著名地标的坐标
2. **高德地图/百度地图**：通过地名搜索获取坐标
3. **国家基础地理信息中心**：标准地名坐标
4. **学术文献**：部分历史地名的考证坐标

## 六、局限性说明

1. **历史变迁**：部分历史地名所指区域随朝代变化，映射仅取最常见对应。
2. **同名异地**：如"东山"在多处有之，仅取最著名的对应地。
3. **泛指地名**：如"江南""塞北"等区域名称，坐标仅取大致中心点。
4. **精度差异**：city/province 级别的坐标取城市中心点，不代表具体位置。
