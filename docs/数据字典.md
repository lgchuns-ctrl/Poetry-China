# 数据字典

## 一、作品数据（works.json）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `id` | string | 作品唯一 ID | `"w_00001"` |
| `title` | string | 标题 | `"春思"` |
| `author` | string | 作者 | `"李白"` |
| `dynasty` | string | 朝代 | `"唐"` / `"宋"` |
| `content` | string | 正文（换行符连接） | `"燕草如碧丝..."` |
| `places` | array[string] | 提及的地名列表 | `["长安", "燕"]` |
| `imagery` | array[string] | 提取的意象列表 | `["月", "风", "花"]` |
| `themes` | array[string] | 主题分类 | `["思乡", "边塞"]` |
| `season` | string | 季节 | `"春"` / `"夏"` / `"秋"` / `"冬"` / `""` |
| `mood` | string | 情感 | `"豪迈"` / `"婉约"` / `""` |

## 二、地名数据（places.json）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `place_id` | string | 地名唯一 ID | `"pl_0000"` |
| `place_name` | string | 地名 | `"长安"` |
| `place_name_normalized` | string | 规范化名称 | `"长安"` |
| `place_type` | string | 地点类型 | `"city"` |
| `historical_name` | string | 历史名称 | `"长安"` |
| `modern_name` | string | 现代名称 | `"西安"` |
| `modern_province` | string | 现代省份 | `"陕西"` |
| `modern_city` | string | 现代城市 | `"西安市"` |
| `longitude` | float | 经度 | `108.94` |
| `latitude` | float | 纬度 | `34.27` |
| `mapping_level` | string | 映射级别 | `"city"` |
| `mapping_source` | string | 映射来源 | `"dictionary"` |
| `aliases` | array[string] | 别名列表 | `["镐京", "大兴"]` |

### 地点类型枚举

| 值 | 说明 | 示例 |
|----|------|------|
| `city` | 城市 | 长安、洛阳、扬州 |
| `mountain` | 山岳 | 泰山、华山、庐山 |
| `river` | 河流 | 黄河、长江、渭河 |
| `lake` | 湖泊 | 洞庭湖、鄱阳湖、西湖 |
| `pass` | 关隘 | 玉门关、阳关、潼关 |
| `building` | 建筑 | 黄鹤楼、岳阳楼、寒山寺 |
| `historic_region` | 历史区域 | 江南、塞北、巴蜀 |
| `other` | 其他 | 赤壁、华清池 |

## 三、地名摘要（place_summary.json）

键为地名，值为包含以下字段的对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| `place_id` | string | 地名 ID |
| `place_name` | string | 地名 |
| `place_type` | string | 类型 |
| `modern_name` | string | 现代名称 |
| `modern_province` | string | 省份 |
| `longitude` | float | 经度 |
| `latitude` | float | 纬度 |
| `mapping_level` | string | 映射级别 |
| `mention_count` | int | 总提及次数 |
| `tang_count` | int | 唐诗提及次数 |
| `song_count` | int | 宋词提及次数 |
| `authors` | array[string] | 关联诗人列表 |
| `work_ids` | array[string] | 关联作品 ID 列表 |

## 四、诗人数据（authors.json）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `name` | string | 姓名 | `"李白"` |
| `dynasty` | string | 朝代 | `"唐"` |
| `work_count` | int | 作品数 | `864` |
| `place_count` | int | 涉及地名数 | `52` |
| `places` | array[string] | 涉及地名列表 | `["长安", "庐山", ...]` |
| `desc` | string | 生平简介 | `"字太白..."` |

## 六、分析数据

### dynasty_place_summary.json
唐/宋各地点提及频次汇总。

### imagery_summary.json
意象出现频次统计，按类别分组。

### themes.json
主题分类及各主题作品数。

### author_place_matrix.json
诗人×地名矩阵，记录每位诗人提及各地点的次数。

### conclusions.json
数据驱动的研究结论列表（8 条），由程序自动生成。

### methodology.json
数据处理方法说明，包含数据源、处理步骤、NER 验证结果和局限性。

### metadata.json
项目元数据，包含项目名称、版本、生成时间、数据源和统计摘要。
