# 数据源登记表

## 主数据源

| 项目 | 内容 |
|------|------|
| **名称** | chinese-poetry |
| **URL** | https://github.com/chinese-poetry/chinese-poetry |
| **许可证** | MIT License |
| **数据格式** | JSON |
| **内容** | 全唐诗、全宋词、诗人信息 |
| **采集方式** | Node.js https 模块下载 GitHub raw content |
| **采集脚本** | `scripts/collect/download_data.js` |

### 采集明细

| 数据集 | 文件数 | 记录数 | 路径 |
|--------|--------|--------|------|
| 唐诗 | 15 | 15,008 | `data/raw/poet.tang.*.json` |
| 宋词 | 6 | 6,000 | `data/raw/ci.song.*.json` |
| 唐诗作者 | 3 | 2,856 | `data/raw/authors.tang.*.json` |
| 宋词作者 | 2 | 1,506 | `data/raw/authors.song.*.json` |
| 唐诗标题/序注 | 1 | - | `data/raw/poet.tangtitle.json` |

### 数据字段

**唐诗/宋词作品字段：**
- `title` — 标题
- `author` — 作者
- `paragraphs` — 正文（数组，每句一行）
- `notes` — 注释（部分作品有）

**作者信息字段：**
- `name` — 姓名
- `desc` — 生平简介

## 数据处理流程

```
GitHub raw content（繁体 JSON）
        ↓ download_data.js
data/raw/（繁体原始数据）
        ↓ convert_t2s.js（opencc-js）
data/interim/（简体中间数据）
        ↓ process_pipeline.py（NER + 分析）
data/processed/ + web/public/data/（最终 JSON）
```

## 数据完整性说明

1. 原始数据为繁体中文，已通过 opencc-js 转换为简体。
2. 部分诗人（如李清照、陆游、姜夔）因异体字问题，繁简转换后作品数显示为 0，不影响整体分析。
3. 所有数据均来自公开开源项目，可自由使用。
