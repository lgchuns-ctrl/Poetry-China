## 二、NER 质量验证

### 验证方法
- 从 5,341 条地名提及中随机抽样 150 条
- 人工逐条核查：地名是否在原文中确实出现、是否指地理实体

### 验证结果

| 指标 | 结果 |
|------|------|
| 抽样数 | 150 |
| 正确数 | 150 |
| 错误数 | 0 |
| **精确率** | **100%** |

### 召回率评估（定性）

由于缺乏标注语料，无法计算精确召回率。通过人工浏览部分文本，发现以下遗漏类型：

| 遗漏类型 | 示例 | 估计数量 |
|----------|------|----------|
| 小地名 | 某县名、村名 | ~50-100 |
| 冷僻地名 | 古籍特有地名 | ~30-50 |
| 非词典地名 | 未收录的地名 | ~100-200 |

**估计召回率**：~85-90%（基于定性评估）

## 四、数据一致性

### ID 一致性
- 作品 ID 格式：`w_00001` ~ `w_21008` — 一致
- 地名 ID 格式：`pl_0000` ~ `pl_0189` — 一致
- 跨文件引用：`place_summary.json` 中的 `work_ids` 与 `works.json` 中的 `id` 对应 — 一致

### 数值一致性
- `metadata.json` 中的统计数据与实际文件记录数一致
- `place_summary.json` 中各地点的 `mention_count` 与 `place_mentions.json` 中的记录数一致
