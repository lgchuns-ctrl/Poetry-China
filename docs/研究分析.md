# 研究分析

## 一、数据概览

本项目分析了 21,008 首唐诗宋词，涵盖 1,141 位诗人，识别 190 个文学地点，共 5,341 次地名提及。以下分析结论均由程序自动生成，基于客观数据统计。

## 二、核心发现

### 发现一：长安是诗词中被书写最多的地点

长安（今西安）在全部数据集中被提及 347 次，其中唐诗 297 次、宋词 50 次，远超其他地点。这反映了长安作为唐帝国首都的中心地位——它不仅是政治中心，也是文学创作的核心场域。

### 发现二：唐诗与宋词的地理关注存在显著差异

唐诗中提及频率最高的是长安、洛阳等北方政治中心，而宋词中江南地区（杭州、苏州、扬州）的比重明显上升。这一变化折射了中国经济文化重心南移的历史趋势。

### 发现三：杜甫的文学地理覆盖最广

在作品数≥5 的诗人中，杜甫涉及 86 个不同地点，远超其他诗人。这与其"读万卷书，行万里路"的人生经历一致——他足迹遍及中原、关中、巴蜀、荆湘，诗歌空间极为广阔。

### 发现四："月"和"风"是最普遍的意象

"风"出现在 7,590 首作品中，"月"紧随其后。这两个意象穿越了朝代、主题和诗人的界限，构成了中国诗词最基本的自然意象底色。

## 七、局限性声明

1. **数据集局限**：宋词仅 6,000 首，唐诗 15,008 首，数量不平衡影响对比公正性。
2. **NER 召回**：词典法无法覆盖所有地名，小地名和冷僻地名有遗漏。
3. **体裁差异**：诗与词的篇幅和表达方式不同，地名出现频率不完全可比。
4. **选择偏差**：chinese-postry 数据集并非全唐诗/全宋词的完整收录。
5. **映射精度**：部分历史地名的现代映射为近似值，尤其区域类地名。
