# 网页设计说明

## 一、设计理念

### 主题定位
"诗行中国"——以诗词为线索，以地图为载体，在千年文字中重新看见中国山河。

### 视觉风格
**水墨宣纸风格**：以中国传统书画美学为基调，营造古典文人气质。

### 色彩系统

| 变量 | 色值 | 用途 |
|------|------|------|
| `--color-bg` | #f5f1e8 | 宣纸白（主背景） |
| `--color-ink` | #1a1a1a | 墨黑（正文） |
| `--color-accent` | #8b3a3a | 朱砂红（强调/唐诗） |
| `--color-song` | #2e5c6e | 青黛（宋词） |
| `--color-muted` | #6b6b6b | 淡墨（辅助文字） |
| `--color-border` | #d4cfc0 | 旧纸边（边框/分割） |
| `--color-card` | #fdfaf3 | 宣纸亮（卡片背景） |

### 字体

```css
font-family: "Noto Serif SC", "Source Han Serif SC", "SimSun", "STSong", serif;
```

衬线字体为主，体现古典气质。

## 二、布局结构

### 整体架构
单页滚动应用（SPA），顶部固定导航栏 + 6 个垂直排列的视图区块。

### 导航栏
- 固定在页面顶部
- 6 个导航项：首页、诗词地图、唐宋对比、诗人行迹、全文检索、数据方法
- 滚动时自动高亮当前区块
- 移动端折叠为汉堡菜单

### 视图区块

#### 1. 首页（HomeView）
- **Hero 区**：大标题"诗行中国"，逐字动画淡入，水墨晕染背景
- **数据统计**：唐诗/宋词/诗人/地名四组数字，滚动可见时动画计数
- **经典诗词**：12 首代表性诗词卡片，毛笔字体效果
- **数据发现**：关键结论展示

#### 2. 诗词地图（MapView）
- **主体**：ECharts geo scatter 中国地图，地点以散点标注
- **散点样式**：按地点类型分形状（圆/三角/菱形/矩形/图钉），按提及次数分大小
- **交互**：点击地点弹出详情面板
- **筛选器**：朝代（全部/唐/宋）、诗人、主题、意象 四维筛选
- **详情面板**：地点统计、关联诗人、代表作品、意象标签、主题分布、映射置信度

#### 3. 唐宋对比（CompareView）
- **四个 Tab**：地名、类型、意象、主题
- **对比方式**：左右并排柱状图，唐诗（朱砂红）vs 宋词（青黛）
- **数据声明**：提示不做过度的文化推论

#### 4. 诗人行迹（AuthorView）
- **诗人选择**：标签式切换，按朝代和作品数排序
- **个人地图**：该诗人涉及地点的散点地图
- **统计卡片**：作品数、地名数、最常提及地点
- **代表作品**：展示该诗人提及地名的作品

#### 5. 全文检索（SearchView）
- **搜索框**：支持诗词正文、标题、作者、地名全文检索
- **快捷按钮**：热门地名/诗词一键搜索
- **结果展示**：高亮匹配关键词，显示朝代、作者、地名标签
- **提示卡片**：未搜索时展示搜索建议

#### 6. 数据方法（DataMethodView）
- **数据概览**：总量统计
- **数据来源**：chinese-poetry GitHub 项目信息
- **处理流程**：采集→转换→NER→分析→导出 五步流程
- **NER 验证**：抽样数、精确率展示
- **映射说明**：古今地名对照示例表
- **置信度说明**：6 级映射级别解释
- **技术栈**：Vue 3 / ECharts / Vite / Python

## 三、交互设计

### 动画效果
- 页面滚动时元素淡入
- 数字统计动画计数
- 地图散点 hover 高亮+tooltip
- 导航栏滚动高亮
- 卡片 hover 阴影提升

### 响应式
- 桌面端（>768px）：完整布局
- 移动端（≤768px）：汉堡菜单、单列布局、地图自适应

### 图标系统
- 使用 emoji 和 Unicode 符号（山河、墨、卷轴等）
- ECharts 内置 symbol（circle/triangle/diamond/pin/rect/roundRect）

## 四、技术实现

### 组件通信
- 无全局状态管理（项目规模不需要 Vuex/Pinia）
- 各视图独立管理数据，通过 `utils/data.ts` 统一加载

### 数据加载
- 所有 JSON 文件在 `public/data/` 目录
- 按需加载，首次访问时 fetch 并缓存
- TypeScript 接口定义确保类型安全

### 地图实现
- ECharts 5 `geo` + `scatter` 组件
- 注册 China GeoJSON 地图
- `convertData` 函数将地名转换为 `[lng, lat, value]` 格式
- 自定义 tooltip 展示朝代分布

## 五、性能优化

1. **代码分割**：ECharts 单独 chunk
2. **数据缓存**：fetch 后缓存，避免重复请求
3. **按需渲染**：地图仅在可见时渲染
4. **数据量控制**：search_index 精简为必要字段
