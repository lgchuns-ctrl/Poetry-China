# 项目背景

## 一、选题缘由

中国古典诗词是中华文明的瑰宝，其中蕴含着丰富的地理信息。从李白的"朝辞白帝彩云间"到苏轼的"大江东去"，从王维的"渭城朝雨浥轻尘"到辛弃疾的"醉里挑灯看剑"，每一首诗词都是一幅地理画卷。

然而，传统的诗词研究多以文本分析为主，缺乏空间维度的可视化呈现。随着数字人文（Digital Humanities）的发展，将文学文本与地理信息结合，以地图为载体展现文学空间，已成为人文学科与信息技术交叉的前沿方向。

## 二、项目目标

本项目旨在：

1. **数据挖掘**：从 21,008 首唐诗宋词中系统性提取地理地名，构建诗词地理数据集。
2. **古今映射**：将历史地名映射到现代地理位置，建立古 今地名对照关系。
3. **可视化呈现**：以交互式地图为核心，多维度展现唐宋诗词中的山河版图。
4. **比较研究**：对比唐诗与宋词在地理关注上的异同，揭示文学地理的演变。

## 三、研究意义

### 学术价值
- 为古典文学研究提供空间维度的新视角
- 构建可复用的诗词地理数据集和分析工具
- 探索数字人文方法论在古典文学中的应用

### 文化传播
- 让古典诗词以可视化、交互化的方式触达更广泛的受众
- 帮助读者理解诗词背后的地理语境
- 激发对中国山河的文化认同与审美感受

### 技术探索
- 验证基于词典+规则的 NER 方法在古典文本中的效果
- 探索 Vue 3 + ECharts 在数字人文可视化中的应用
- 积累 OpenHarmony 平台下的前端开发经验

## 四、创新点

1. **三重地名区分**：不仅提取"诗中提及的地点"，还区分诗人写作地和生平地。
2. **多维交叉分析**：地名 × 朝代 × 诗人 × 主题 × 意象，五维度交叉分析。
3. **置信度分级**：古今地名映射按精确程度分为 6 级（exact/city/county/province/approximate/region）。
4. **NER 质量验证**：通过随机抽样人工验证，确保数据可靠性。
5. **数据驱动结论**：所有分析结论均由程序自动生成，避免主观臆断。
